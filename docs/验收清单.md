# 验收清单

对照 UI 原型逐条过一遍，用来发现我可能漏掉或做错的交互细节。测试环境：`php artisan serve` 起本地服务，账号见 [架构与实施方案.md](架构与实施方案.md) 第 7 节。

## 登录 / 角色

- [ ] 登录页能看到验证码图片，点一下图片能换一张
- [ ] 验证码填错，提示"验证码不正确，请重试"，且不会真的尝试登录
- [ ] 工号密码都对但验证码填错，应该登录失败（验证码和密码都要对才能登录）
- [ ] 用错误密码登录，提示"工号 / 手机号或密码不正确"
- [ ] 用 D00001（设计师）登录，看到 Bethel办公楼 + Kerene别墅 两个项目切换标签
- [ ] 用 C00001（施工方）登录，只看到 Bethel办公楼，侧边栏没有"+"添加细分类按钮，细分类详情页没有"上传变更/重命名/删除"按钮
- [ ] 用 A00001（管理员）登录，看到全部 4 个项目、全部 3 个团队，顶部有"进入后台"按钮，且和设计师一样能在侧边栏添加细分类
- [ ] 用 S00001（超级管理员）登录，权限和 A00001 一样都能进后台、管内容
- [ ] 用 D00001（设计师）登录，侧边栏 / 总览页只看到"土建"和"机电"两个团队，看不到"精装"（团队级隔离）
- [ ] 用 C00001（施工方）登录，只看到"机电"一个团队
- [ ] 施工方账号直接在地址栏输入未分配项目的 URL（如 `/projects/2`），应显示 403
- [ ] 退出登录后，直接访问首页应跳转回登录页

## 语言切换（中文 / 法语）

- [ ] 登录页右上角有"中文 / Français"切换，点 Français 后登录页文案（标题、标签、按钮）全部变成法语
- [ ] 登录后顶部导航也有同样的切换，切到法语后主要页面（总览、细分类详情、上传弹窗、语言文件管理弹窗、图纸预览、个人设置、站内通知）文案变成法语
- [ ] 切到法语后，团队/专业/细分类名称、变更说明文字、上传人姓名等实际数据依然按原样显示中文（不会被强行翻译，也不应报错或显示空白）
- [ ] 后台管理（`/admin/*`）页面不受语言切换影响，始终是中文
- [ ] 切回中文后，所有页面恢复原样
- [ ] 退出登录后语言会重置回中文（纯会话级别，不跨账号持久化），重新登录前可以在登录页再切一次

## 个人设置

- [ ] 任意账号登录后，点顶部"个人设置"能改自己的姓名
- [ ] 改密码时，当前密码填错会提示"当前密码不正确"，密码不会被改
- [ ] 当前密码填对、新密码两次一致，能成功改密码，退出重新用新密码登录成功
- [ ] 登录标识（工号/手机号）在个人设置页面是灰色不可编辑的

## 站内通知

- [ ] 设计师给某个团队+项目下的细分类上传新版本后，同项目同团队的施工方账号登录能在顶部看到通知铃铛未读数
- [ ] 上传者自己不会收到这条通知
- [ ] 不同团队/不同项目的账号不会收到这条通知（团队隔离在通知上也生效）
- [ ] 点击某条通知，能直接跳转到对应细分类详情页，并且这条通知变为已读
- [ ] "全部标记已读"按钮能清空未读数

## 总览页

- [ ] 统计卡片数字（分类总数/累计版本/本月新增/含外发语言版本）与侧边栏实际数据一致
- [ ] 按团队筛选（土建/机电/精装）chip 能正确过滤最新变更列表
- [ ] 点击某条最新变更，能跳转到对应细分类详情页

## 细分类详情页

- [ ] 最新版本卡片高亮显示，语言标签（中/FR/EN）只要该语言下有任意一份 DWG/PDF/说明文件就显示绿色，没有的施工方看到灰色虚线、设计师/管理员看到可点击的"+"
- [ ] 点击语言标签，能打开"该语言版本文件"管理弹窗，里面分别列出 DWG 原图、PDF 图纸、说明文件三块，每份文件各自显示上传日期
- [ ] 管理弹窗里能给任意语言追加新的 DWG/PDF（一次可以多选），追加后不影响已有文件
- [ ] 管理弹窗里能单独删除某一份 DWG/PDF，不影响该语言下的其他文件
- [ ] 中文的最后一份 DWG 不能被删除（删除会提示"中文至少需要保留一份 DWG 图纸，不能全部删除"），但中文如果有多份 DWG，删到只剩一份之前都可以正常删
- [ ] 管理弹窗里有"打包下载本语言全部文件（ZIP）"按钮，点击能下载一个包含该语言所有 DWG+PDF+说明文件的 zip
- [ ] 历史版本表格按时间倒序排列，版本号/日期/语言/说明/上传人都对得上
- [ ] 下载图纸/PDF/说明文档能触发浏览器下载，文件内容和上传时一致
- [ ] 删除某个变更版本（"✕"按钮）后，该版本记录消失（软删除，`versions.deleted_at` 有值）；同时其名下所有 DWG/PDF/说明文件从 COS 上被物理删除（不是只删数据库记录），可以在腾讯云 COS 控制台确认对应对象已经不存在，避免存储空间只增不减

## 图纸预览（PDF）

DWG→DXF 交互式预览已停用，图纸预览现在直接读 PDF 文件，用浏览器自带的 PDF 阅读器展示。

- [ ] 某语言下有 PDF 文件时点"预览"，能在弹窗里看到内嵌的 PDF，能用浏览器自带能力翻页、缩放
- [ ] 某语言下有多份 PDF 时，预览弹窗顶部会出现文件选择 chip，点不同的文件能切换显示的 PDF
- [ ] 某语言下没有 PDF（只有 DWG）时点"预览"，显示"暂无图纸预览，可直接下载 DWG / 说明文件查看"，而不是报错或空白
- [ ] 施工方账号看不到自己没权限的团队/项目下的版本预览（直接构造 `/version-drawings/{id}/preview` URL 应返回 403）
- [ ] 直接构造 `/version-drawings/{dwg文件id}/preview`（DWG 而非 PDF）应返回 404，预览路由只对 PDF 开放

## 上传变更

- [ ] 版本号默认自动 +1（如已有 V2，弹窗默认显示 V3）
- [ ] 中文 DWG 为唯一必填项（可以一次多选，比如每层一张），不填会有校验错误提示
- [ ] 中文的 PDF 和说明文件、以及法语/英语的所有文件都是可选的，全部留空也能成功发布（只要有中文 DWG）
- [ ] 法语/英语可以留空，留空后对应语言标签显示为"未上传"
- [ ] 点击"发布变更"后弹窗立即关闭，右上角出现上传进度卡片，实时显示百分比
- [ ] 上传文件传输完成后（100%）文案变成"处理中…"并有脉冲动画，不会让人误以为卡死；服务器处理完成后自动跳转刷新，新版本出现在最新版本卡片里，历史版本表格里多一行旧版本
- [ ] 校验失败（比如文件类型不对）时，进度卡片原地显示具体错误信息，不会误报"发布成功"
- [ ] 刚发布的变更，图纸预览弹窗里该语言版本显示"图纸正在后台转换…"，等 [队列 worker](../README.md) 处理完（一般 1～2 分钟）刷新页面后能看到可交互预览；下载 DWG/说明文档全程不受转换状态影响

## 细分类管理

- [ ] 添加细分类只影响当前项目，切换到其他项目看不到新加的细分类
- [ ] 重命名细分类后，侧边栏和详情页标题同步更新
- [ ] 删除细分类时，密码错误会提示"密码错误，请重试"且不会真的删除
- [ ] 密码正确删除后，该细分类从侧边栏消失；数据库里应该是软删除（`deleted_at` 有值），不是物理删除

## 后台管理（仅管理员）

- [ ] 添加/重命名/删除团队，提示语里说明"全公司共享，影响所有项目"
- [ ] 添加/重命名/删除专业，同上
- [ ] 删除团队/专业前，密码校验逻辑与细分类一致
- [ ] "国家/项目管理"页面：能添加国家、在国家下添加项目，列表正确显示每个国家的项目数、每个项目的细分类数
- [ ] 添加一个还没有项目的新国家后，顶部国家切换栏正确显示为置灰不可点的标签（不会导致整个页面报错），后台页面里也显示"该国家下还没有项目"的空状态提示
- [ ] 删除国家前需要密码确认，提示语说明其下项目会一并不可见；删除项目前需要密码确认，提示语说明其下细分类/变更记录会一并不可见
- [ ] 软删除国家/项目后，直接构造原详情页 URL 应返回 404（而不是报错或者仍能访问）
- [ ] "账号管理"页面能创建新账号、修改角色、勾选可见项目、勾选可见团队、重置密码、禁用账号
- [ ] 禁用后的账号无法登录
- [ ] 用 A00001（普通管理员）登录账号管理页，看不到创建"管理员/超级管理员"角色的选项，已有的管理员账号旁边显示"仅超级管理员可编辑"、没有编辑按钮
- [ ] 用 S00001（超级管理员）登录，能创建/编辑管理员和超级管理员账号

## 权限边界（用多个账号交叉测试）

- [ ] 施工方账号无法通过直接构造 URL 触发上传/删除接口（应返回 403，不是被隐藏了按钮就万事大吉）
- [ ] 设计师账号无法访问 `/admin`（应返回 403）
- [ ] 管理员账号既能进后台，也能像设计师一样正常管理细分类和版本
- [ ] 设计师即使在自己可见的项目里，也无法对不属于自己团队的专业下的细分类做增删改（直接构造 URL 也应返回 403）
- [ ] 普通管理员对已有管理员账号发起编辑请求（直接构造 URL/表单）应返回 403，不能靠前端隐藏按钮兜底

## 上线前专项（生产环境）

- [ ] 连续用错密码登录 6 次以上，第 7 次应该被限流拦下（HTTP 429），而不是一直允许无限重试
- [ ] `php artisan app:create-admin` 能正常交互式创建超级管理员账号；两次密码不一致、登录标识重复时应该报错并且不创建账号
- [ ] 生产环境确认没有跑过 `php artisan db:seed`（后台账号列表里不应该出现 `S00001`/`A00001`/`D00001`/`C00001` 这几个演示账号）
- [ ] `.env` 确认 `APP_DEBUG=false`——故意触发一个报错（比如访问一个不存在的路由），页面上不应该出现完整堆栈信息
- [ ] Nginx 走 HTTPS 的情况下，页面里生成的链接（比如通知里的跳转链接）应该是 `https://` 开头，不是 `http://`（验证 `trustProxies` 生效）
